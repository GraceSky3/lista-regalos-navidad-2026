# 🎄 Lista de Regalos - Cumpleaños y Navidad 2026

Proyecto web multipágina con temática navideña para compartir mi lista de deseos con la familia.

## 📂 Estructura de archivos

- `index.html`: Portada principal con acceso a las secciones.
- `ropa.html`: Sección de pantuflas y pijamas de Bambi (Primark).
- `munecas.html`: Sección de muñecas Monster High organizadas por colecciones.
- `css/styles.css`: Todos los estilos navideños, colores y animación de nieve.
- `js/data.js`: Base de datos limpia con todos los regalos (fácil de editar).
- `js/app.js`: Lógica compartida (nieve, reservas en memoria y botón de copiar para WhatsApp).

## 🚀 Cómo subirlo a GitHub Pages

1. Descomprime este archivo `.zip` en tu ordenador.
2. Crea un repositorio público en GitHub.
3. Sube todos los archivos y carpetas (`index.html`, `ropa.html`, `munecas.html`, `css/` y `js/`).
4. Ve a **Settings > Pages**, selecciona la rama `main` y guarda.
